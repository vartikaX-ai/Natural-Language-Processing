# Text Classification

# About this Repository

This repository contains my implementations and practical projects related to **NLP Text Classification**.

Text Classification is an NLP task in which text is assigned to predefined categories based on its content.

## Topics Covered

- Text Classification
- Sentiment Analysis
- Multiclass Classification
- Label Encoding
- TF-IDF Vectorization
- Logistic Regression
- Model Evaluation
- Confusion Matrix
- Classification Report

## Practical Implementations

### Sentiment Analysis

Implemented a **multiclass sentiment classification** system using:

- TF-IDF
- Logistic Regression
- Label Encoding
- Train-Test Split
- Stratified Sampling

The model classifies text into five sentiment categories:

- Anger
- Fear
- Joy
- Neutral
- Sadness

### Dataset

The **DailyDialog** dataset is used for the sentiment analysis practical.

### Evaluation

The model is evaluated using:

- Accuracy
- Macro Precision
- Macro Recall
- Macro F1 Score
- Confusion Matrix
- Classification Report

### Results

| Metric | Score |
|---|---:|
| Accuracy | 68.58% |
| Macro Precision | 68.90% |
| Macro Recall | 68.64% |
| Macro F1 Score | 68.51% |
